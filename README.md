# B＋85 退休年度規劃工具（瀏覽器版）

這是 **免費 GitHub Pages 網站的公開程式原始碼**，適合一般使用者在瀏覽器進行年初預算、年末結算與年度紀錄備份。它不會連接銀行或券商，不會下單或提領，且尚非正式 ACTIVE 的真實提款系統。

## 開啟網站

啟用 GitHub Pages 後，網站網址為：

**https://rucifa.github.io/retirement-b85-web/**

程式首次需要連線下載固定版本的 Pyodide / NumPy；**使用者無需安裝 Python**。後續每次年初輸入資產、已知 CPI 與日期，查看 B＋85 建議；年末輸入實際支出及資產餘額，按確認結算。

## 2026-10-12 首頁介面改版

公開網站的首頁已改為**柔和青綠色儀表板、上方橫向導覽列**，原有年初核准、年末結算與年度紀錄匯出匯入功能保留。新增官方 CPI 月度折線圖、B＋85 結果摘要卡、2026 固定實質生活費基準、Guardrail 政策說明，以及根據**已結算年度**繪製的資產歷史曲線。

- 圖片設計稿的示範數字與未來預測曲線**不直接用於正式畫面**；尚無實際核准或結算資料時，顯示「尚未試算」或「尚無紀錄」。
- 生活費卡片顯示 v3.3.9 固定 2026 年實質基準：正常 65 萬、核心 60 萬、Floor 50 萬（均為年額）；安全現金目標是退休啟動時名目 240 萬，不等於當年實際餘額。
- 官方 CPI 短期曲線含已發布但尚待核對的月份，並以虛線區分；不能以單月指數推斷尚未公布的 2026 全年基準。
- `static/dashboard.css` 與 `static/dashboard.js` 僅負責版面、彙整本機已計算的結果和公開物價資料；`policy/retirement_model_v340.py` 政策雜湊不變。
- GitHub Actions 以 Chromium 真實 Pyodide 執行年初／年末／備份及新增儀表板 UI 回歸測試。通過完整流程之前不視為生產正式 ACTIVE。

## 資料與隱私

- 財務紀錄保存在使用者自己的瀏覽器 IndexedDB，**不自動上傳 GitHub、Google 或本站伺服器**。
- 需要跨裝置、重新安裝瀏覽器或清除瀏覽器資料時，請先匯出 JSON，再於新瀏覽器匯入。此 JSON 可能包含敏感的財務資料，請妥善保管。
- 本公開儲存庫只有靜態 UI 和通用退休政策演算法，**不包含個人持倉、年度紀錄、GitHub 密碼或私人研究備份**。
- USD/TWD 假設固定 30；畫面上的 2036、27,000,000 及原始 CPI 輸入數字純屬演練假設，並非個人事實或官方查證值。
- 網站會自動從同源 `./data/cpi_verified.json` **讀取**公開的主計總處 CPI 快照，區分雙來源查證、公告待核對及歷史修訂差異；不會把公告未核對月份或 2026 單月值當作已認證全年資料，也不會改寫已保存年度。
- **公開網站改採獨立官方 CPI 排程**：`.github/workflows/cpi-public-scheduled.yml` 已設每月 1、15 日台灣時間 10:32（GitHub cron 為 UTC 02:32），直接在 `retirement-b85-web` 下載主計總處官方歷史 XLS＋新聞稿 Table-1 XLSX，驗證 TWCA HTTPS 憑證、811 個月歷史基準 SHA256、雙來源一致性、發布時間與資料安全後，用**本儲存庫內建 `GITHUB_TOKEN`** 只更新 `data/cpi_verified.json` 與 `SOURCE_SHA256.json`；再明確要求 Pages 重建並比對正式網站 JSON。**不需要私人 repo Token、不需要跨庫同步或額外費用**。程式已提交，但須以實際 Actions 執行綠燈與正式網頁快照更新，才能視為無人值守驗收成功。私人研究庫保留自己原有的獨立 CPI 排程。
- 「2026 年全年 CPI」截至 2026-10-11 仍未正式產生；因此公開區暫無可用的 2026 年全年基準，官方累積物價變化與官方換算後生活費顯示不可計算；手動演練不受影響。

## GitHub Pages 一次性設定

在 [Settings → Pages](https://github.com/rucifa/retirement-b85-web/settings/pages) 選擇 **Deploy from a branch**，Branch 選 **main**，Folder 選 **/(root)**，按 Save。Pages 顯示已發布後，開啟上面網址。
