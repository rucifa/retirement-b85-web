- **核心模型不變**：v3.3.9 FROZEN 與 \`policy/retirement_model_v340.py\` 均未變更，新增 \`calendar_first_year.py\` 作為年度帳本適配層。

## 官方 CPI 最新公告顯示原則（2026-10）

- 公開首頁以 GitHub Pages 的 \`data/cpi_verified.json\` 作為**唯讀唯一展示來源**，不在訪客瀏覽器直接抓主計總處網站。
- GitHub Actions 對**主計總處正式新聞稿與附表 XLSX**核對之後，網站可立即顯示最新已公布月份的**官方同月年增率**；歷史 CPI 主表晚於新聞稿同步時，主畫面不再顯示「待雙來源核對」遮蔽最新年增率。
- **原始 JSON verification 仍保留** \`CROSS_VERIFIED\`、\`BULLETIN_ONLY_PENDING_PRIMARY\`、\`HISTORICAL_VINTAGE_DIFFERENCE\`，並在 CPI 進階資料揭示，以便日後追蹤修訂；不將其偽造成全面已查證。

- 月度同比年增率**不是**年度 CPI 平均基準。缺少已認證 2026 全年 CPI 指數時，2026 實質生活費正式調整不應由單月數字推論，模型仍使用明確標示的演練假設。

## 2026-10-12 介面與日期規則

- 首次進入頁面時，**年初決策日期輸入框**依瀏覽器目前時鐘換算為台灣 `Asia/Taipei` 民用日期；不會假裝 GitHub Pages 存在台灣本地授時伺服器。用戶可手動改日期；已儲存年度仍以帳本的下一年度決策日為準，不能被這個預設覆蓋。
- **B＋85 核心採一月年初一次提領**：當系統今日不是一月，頁面會出現明確提示及「改用該年度 1 月 15 日試算」的動作。切換到一月時，若已預選的 CPI 是一月決策日之後才公布，會清掉該 CPI／發布日期，避免未來資料洩漏進歷史試算；不能偷偷改成今天決策。
- 退休開始年齡一般示範預設 **65 歲**，對照 2026 起勞保老年年金法定請領年齡，**並非強制或所有人的退休年齡**。勞退新制年滿 60 歲可請領個人退休金，與勞保年金不同；使用者可自行設定退休開始年齡，已存計畫不變。
- CPI **公開快照**以台灣今日為查詢時點，最多回看上一個完整曆月，且只接受查詢時點之前已發布的月份；分別顯示最近「雙來源已查證」月份與上個月「已公布／待確認」狀態。不能把模擬的 2036 年日期視為今天的官方資料。
- 第一次尚未有年度紀錄、使用者也未自行輸入時，可以帶入與年初決策日相容、公布未超過 120 天的**已雙來源核對月度 CPI**和其官方發布日；對於待核對月份／過期／決策日之後的 CPI 不會自動帶入。**2026 全年 CPI 年平均仍未知**；初始的 2026 年 CPI =110 是明確標示的手動演練假設，不能冒充官方全年基準。
- 2026 實質生活費基準（正常／核心／Floor）與通膨換算後正常生活費的數值，**只有在 B＋85 首次年初試算成功後才顯示**。年初試算前不提供未經授權的預算結論；公開 CPI 區也不預先計算任何全年真實購買力調整。
